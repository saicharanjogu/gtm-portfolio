# Sai Charan Jogu · Product & GTM portfolio

One-page portfolio: lead gen → demos → value engineering → paid POC → production.

Built with Vite, React, TypeScript, Tailwind CSS v4 and Motion. The animated components in `src/components/ui/` are adapted from
Magic UI, Aceternity UI, React Bits and Motion Primitives patterns.

## Develop

```bash
npm install
npm run dev
```

## Edit content

All copy, metrics and contact details live in `src/lib/content.ts`. Set `profile.linkedin` to show the LinkedIn button.

## Deploy

`npm run build` outputs a static site to `dist/`. Import the repo on Vercel or Netlify with the default Vite settings.
